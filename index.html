The bundled Forth cartridge. Opens a fresh emulator and starts automatically.

Integer BASIC

Woz's Apple-1 BASIC on the CoCo, with a native 40×24 graphics terminal.

At Color BASIC’s OK prompt: CLOADM, wait for OK, then EXEC.

Blackjack

The historical Apple-1 game. Start Integer BASIC using its tape above, then mount this program tape.

In Integer BASIC, type LOAD "BLACKJAK", wait for LOADED, then RUN.

The first shuffle can pause at “I SHOW” for about 20 seconds at normal speed.

Apple Star-Trek (1977)

Based on Mike Mayfield's original Star Trek, adapted for Apple-1 BASIC by Robert J. Bishop. Explore, scan and battle Klingons.

Start Integer BASIC using its tape above, then mount this program tape.

In Integer BASIC: HIMEM=27904, then LOAD "STARTREK". Wait for LOADED, then RUN.

Enter 1 at “TYPE A NUMBER”. Commands: 1 short scan, 2 long scan, 5 computer. Initialization takes time. The original scan layout fits the 40×24 terminal.

Mike Mayfield's Star Trek

Our Integer BASIC adaptation of Mike Mayfield's HP listing. Original attribution is retained; course and warp inputs use tenths.

Start at Color BASIC's OK prompt (Reset if needed). Type CLOADM, wait for OK, then EXEC. This larger game requires the 64K build.

In 64K Integer BASIC: LOAD "MIKETREK", wait for LOADED, then RUN. Answer YES or NO for instructions. Course 15 means 1.5; warp 2 means 0.2.

At normal CoCo speed, the first mission takes about 2½ minutes to initialize and draw its board.
